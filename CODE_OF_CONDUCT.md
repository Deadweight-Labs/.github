# Code of conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent and criticise the work, not the person. We don't tolerate harassment, discrimination or personal attacks.

To report a problem, email [team@deadweightlabs.com](mailto:team@deadweightlabs.com). We read every report and treat it confidentially.
