# Security policy

This policy applies to every Deadweight Labs repository that does not ship its own `SECURITY.md`.

## Reporting a vulnerability

Email [security@deadweightlabs.com](mailto:security@deadweightlabs.com). Please include:

- the affected repository and version or commit,
- steps to reproduce,
- the impact you expect, and
- any workaround you already know.

Do not open a public issue for a vulnerability that hasn't been disclosed yet, and don't send live credentials.

We acknowledge reports within five business days. How quickly we fix and disclose depends on severity. We don't run a bug bounty program.
